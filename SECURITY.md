# Security

Please report security issues privately through GitHub's **Report a vulnerability** action on the repository's Security tab. Include reproduction steps and the affected endpoints. Do not post credentials, private player data, or exploit details in public issues.

The project does not ask for Minecraft or Microsoft passwords. Browser uploads require a short-lived, one-use ticket issued by the TongCraft Sync mod; only the Sync service sees the player's Minecraft session proof.
